# Bloqueo y desbloqueo de tarjeta

## Bloqueo
El bloqueo es inmediato y se puede hacer desde la app o desde atención. Se recomienda bloquear ante pérdida, robo o compras no reconocidas.

## Desbloqueo
Si la tarjeta se bloqueó por sospecha de fraude, no se desbloquea desde atención: se emite una tarjeta nueva, que llega en 5 a 7 días hábiles.

## Tarjeta virtual
Mientras llega la tarjeta nueva, el cliente puede generar una tarjeta virtual desde la app para seguir operando.
