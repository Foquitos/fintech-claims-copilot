# Reintegros y límites de aprobación

## Quién puede aprobar
Los reintegros de hasta $50.000 los aprueba el sistema de forma automática. Los reintegros mayores a $50.000 requieren aprobación de un supervisor antes de acreditarse.

## Monto máximo
Un reintegro nunca puede superar el monto del movimiento original.

## Clientes nuevos
Para cuentas con menos de 90 días de antigüedad, todo reintegro mayor a $20.000 se deriva a supervisión, sin importar el motivo.

## Registro
Todo reintegro debe registrar el motivo y el número de movimiento asociado.
