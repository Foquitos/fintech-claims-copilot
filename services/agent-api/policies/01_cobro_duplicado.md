# Cobro duplicado

## Cómo identificarlo
Hay cobro duplicado cuando aparecen dos o más compras aprobadas al mismo comercio, por el mismo monto, con menos de 30 minutos de diferencia y el cliente confirma que hizo una sola compra.

## Qué hacer
Verificar los dos movimientos en el historial del cliente. Si se cumplen las condiciones, se reintegra el monto de uno de los cobros. El reintegro se solicita sobre el segundo movimiento.

## Plazos
El reintegro por cobro duplicado se acredita dentro de las 48 horas hábiles. Informar el número de solicitud al cliente.

## Excepciones
Si los montos son distintos o pasaron más de 30 minutos entre las compras, no se trata como duplicado: se deriva como desconocimiento de compra.
